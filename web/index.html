Pilih satu gambar — deteksi langsung jalan.
Video diputar di browser; frame diambil berkala lalu dikirim ke API. Frame yang datang saat request sebelumnya belum selesai akan dilewati, jadi playback tidak menumpuk antrean.
Butuh izin kamera. Browser hanya mengizinkan getUserMedia di localhost atau HTTPS.

Sensitivitas

Berapa frame per detik yang dikirim ke API saat mode video / webcam. Turunkan kalau server terasa berat.
